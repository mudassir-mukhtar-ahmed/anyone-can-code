Proposed Workshop Outline · For Board Review

Anyone Can Code

From Idea to App with AI

Format
Online, instructor-led, hands-on
Duration
Approximately 4 hours
Audience
Community members of all experience levels — beginners, students, adults, and IT professionals
Prerequisites
No prior coding experience required

Recommended: participants join from a computer with access to the required AI coding tools.

Workshop Overview

Anyone Can Code is an introductory, hands-on workshop designed to help community members understand modern Artificial Intelligence and experience how AI tools can assist with building software.

The workshop is intentionally designed for a broad audience. It does not assume prior programming knowledge and will focus on concepts, practical demonstrations, and guided hands-on learning rather than traditional programming syntax.

By the end of the workshop, participants will have a basic understanding of how modern AI works, how software applications are structured, and how to use an AI coding assistant to build and improve a simple application.

01 Introduction: Anyone Can Code

The workshop will begin by exploring how AI is changing the way software is created and lowering the barrier for people who have never programmed before.

A short live demonstration will show how an idea described in everyday language can be turned into a working application with the help of an AI coding assistant.

Purpose

Establish what is possible with modern AI and introduce the theme of the workshop.

02 Understanding AI and Large Language Models

Participants will receive a beginner-friendly introduction to Artificial Intelligence and Large Language Models (LLMs). Topics will include:

  • What Artificial Intelligence means
  • What an LLM is
  • A high-level explanation of how LLMs generate responses
  • The difference between an AI model and traditional software

The explanation will remain conceptual and will not require mathematics or a computer science background.

Purpose

Give participants a practical mental model of the technology they will be using.

03 Tokens and Context

Participants will learn two important concepts behind modern AI systems:

  • Tokens — how AI models process pieces of text and information.
  • Context — the information available to an AI model when it generates a response.

The session will demonstrate how providing better context and clearer information can significantly improve AI-generated results.

Purpose

Help participants understand why the quality of their instructions and information matters when working with AI.

04 Communicating Effectively with AI

Participants will learn a simple framework for giving AI useful instructions. The focus will be on clearly communicating:

  • The goal
  • Relevant context
  • Requirements
  • Constraints

Participants will also learn that working with AI is usually an iterative process: describe what you want, review the result, test it, and continue improving it.

Purpose

Teach a practical skill that applies to both AI coding and general use of AI tools.

05 How Software Applications Work

Before beginning the coding exercise, participants will receive a high-level introduction to the major components of a modern software application. The following terms will be explained in simple language:

  • Frontend — what the user sees and interacts with
  • Backend — the logic and processing behind an application
  • Database — where application data is stored
  • API — how different software components communicate
  • Server / Cloud — where applications and services can run

No programming syntax will be required.

Purpose

Give beginners enough technical vocabulary to understand what an AI coding assistant is creating.

06 Coding with AI

Participants will see how an AI coding assistant can translate natural-language requirements into software. The session will demonstrate a practical development cycle:

Idea → Describe → Generate → Test → Improve

The instructor will also explain the role of the human in reviewing requirements, making decisions, testing results, and guiding the AI.

Purpose

Show that AI can assist with implementation while reinforcing the importance of human understanding and judgment.

07 Hands-On Project: Personal Expense Tracker

Participants will build a simple Personal Expense Tracker with guidance from the instructor and an AI coding assistant. The application will begin with basic functionality such as:

  • Entering an expense
  • Recording an amount and category
  • Displaying expenses
  • Calculating total spending

As the exercise progresses, participants may add features such as filtering, persistent storage, charts, budgets, search, or other improvements.

The project is designed so that beginners can follow the guided version while more experienced participants can experiment with additional features.

Purpose

Give every participant practical experience turning an idea into a working application.

08 Q&A

The workshop will conclude with an open question-and-answer session, giving participants a chance to ask about anything covered during the workshop.

Purpose

Address remaining questions and reinforce what participants learned before they continue on their own.

Expected Outcomes

By the end of the workshop, participants should have:

  • A basic understanding of AI and Large Language Models
  • An understanding of tokens and context
  • A practical framework for communicating with AI
  • Familiarity with frontend, backend, databases, APIs, and cloud concepts
  • Hands-on experience using AI to build a simple application
  • Experience testing and improving AI-generated code
  • A foundation for continuing to learn and experiment independently
